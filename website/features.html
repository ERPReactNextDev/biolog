01 — Attendance

Clock In & Clock Out

The core loop, built to be unarguable. A clock-in is a photo, a location with a stated accuracy, and a timestamp — so a disputed shift is settled by looking at the record rather than by remembering.

  • Photo captured on every action, with optional face matching against the registered agent
  • GPS keeps the best fix within a 15-second window rather than accepting the first, inaccurate reading
  • Accuracy is graded — Excellent, Good or Poor — and a poor fix is flagged in amber, never hidden
  • Manual location override when the GPS is wrong: drag the pin or type an address, and it is recorded as manual
  • Status colours are consistent everywhere, so on-duty and off-duty are unmistakable at a glance
  • Client-site boundaries warn an agent who has strayed too far, and require a photo plus a note

02 — Field work

Site Visit Logging

A client visit is not an attendance entry with a note attached. It is its own record: who was visited, by whom, when, with proof — and it stays that way when you export it.

  • Client type recorded as New or Existing, so pipeline and coverage stay distinguishable
  • A photo per visit, kept with the record rather than in a separate album
  • Remarks and contact details captured on the spot, not reconstructed from memory later
  • Downloadable proof for a client — photo, time, location, agent name
  • Viewed in the calendar, so the day's route is legible at a glance
  • Clients outside their mapped boundary are flagged for review rather than silently accepted

03 — Connectivity

Offline & GPS Reports

Most field problems are connectivity problems. An agent in a basement or a provincial barangay still has to record the shift, and the system has to be honest about when that record was made.

  • Logs queue on the device with photo and coordinates intact when there is no signal
  • Automatic sync the moment the connection returns, with a pending count so the agent knows
  • Last known location is stored locally and used offline, explicitly marked as needing review
  • Flagged rows surface in a review queue with the accuracy figure and distance shown
  • Admins mark a flagged record as reviewed without altering the original measurement

04 — Insight

Reports & Timesheets

Hours calculated against the work day your company actually runs. A shift that starts at 10 PM belongs to the previous day, and a report that gets that wrong is worse than no report.

  • Work-day boundary is configurable, so night shifts are attributed correctly
  • Late arrivals and overtime derived from the grace period you set
  • Excel export for the whole team or a single agent, ready for payroll
  • Filter by date range, team, manager or individual agent
  • Team rollups for supervisors who manage more than their own attendance

05 — Control

Security

Access is a decision you make once per person, not a setting buried in a menu. Attendance data is only as trustworthy as the permissions around it.

  • Email OTP for password reset, with account lockout after repeated failures
  • Face verification per agent, toggleable — useful where a shared device is unavoidable
  • Roles from Super Admin down to individual agent, plus per-user permission overrides
  • Every administrative action is written to an audit log with who and when
  • Multi-company support, so each tenant only ever sees its own records
